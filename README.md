# Lexyom

Lexyom (Lexyom LLP) is a law firm serving financial-services companies, with published offices in New York (450 Park Avenue) and Dubai (DIFC Gate Village). Its practice covers financial institution setup, company registration, broker and proprietary-trading ("prop firm") licensing, trademark registration and IP protection, retainer representation, and contract drafting and review.

Website: https://lexyomlaw.com (lexyom.com redirects here)
